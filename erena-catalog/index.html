初めて使う方へ — 使い方ガイド (クリックで開く)

基本の流れ

  1. 「未発送」タブで新規受注を確認
  2. 発送準備ができたら「発送処理」ボタン(または一括発送)→ 運送会社・追跡番号を入力
  3. 発送後は「発送済み」タブに移動
  4. 商品が着荷したら「WEBEDI計上/問屋報告」(直納商品or問屋経由で文言違い)

発送処理の方法 (3通り)

  • 1件ずつ: 各行の「発送処理」ボタン → モーダルで入力
  • 選択して一括: チェックボックスで複数選択 → 「選択した注文を発送処理」
  • CSVで一括: 「CSVダウンロード」→ Excel等で運送会社・追跡番号を入力 → 「CSVアップロード」

数量が複数で伝票が分かれる場合

  • 発送処理モーダル内の「追跡番号をもう1件追加」で複数の伝票を一度に登録できます
  • 後日追加で発送する場合は、発送済タブの「伝票追加」ボタンから追記可能

間違えた時の取消

  • 「発送取消」: 発送状況を未発送に戻す (運送会社・追跡番号・発送日時・WEBEDI状況をクリア)
  • 「計上取消」: WEBEDI計上/問屋報告を未完了に戻す
  • ※ どちらも確認ダイアログが出ます

集計カードの見方

  • 今日/今週/今月 受注: 期間内に店舗から受けた注文件数
  • 未発送・要対応: 発送処理が必要な件数(赤色)
  • WEBEDI計上待ち: 発送済だがWEBEDI計上 or 問屋報告が残っている件数(オレンジ色)

登録商品タブ

  • 自社が登録している商品の詳細(価格・内容量・賞味期限・お盆休み等)を確認できます
  • 商品マスタの修正依頼は エレナ ギフト事務局(info@yui.gift / 03-6441-0931) までご連絡ください
ご不明点は エレナ ギフト事務局(info@yui.gift / 03-6441-0931) までお問い合わせください。

CSVダウンロード→入力→アップロードで一括発送する手順
  1. 「CSVダウンロード」をクリック → 未発送注文一覧のCSVが保存されます
  2. Excel等で開いて、「運送会社」列と「追跡番号」列に値を入力します
    • 「運送会社」は ヤマト運輸 / 佐川急便 / 日本郵便 / その他 のいずれか
    • 「追跡番号」は半角数字・ハイフンで入力
    • 「rowIdx」列は絶対に編集しない(システム識別子のため)
    • 発送しない行は空欄のままでOK(処理対象外になります)
    • 1注文で伝票が複数に分かれる場合は、同じ行をコピーして増やし(rowIdxはそのまま)、それぞれに運送会社・追跡番号を入力すれば複数伝票としてまとめて登録されます
  3. 保存(CSV形式のまま)
  4. 「CSVアップロードで一括発送」から保存したCSVを選択
  5. 運送会社・追跡番号が両方入力された行のみ、一括で発送済みに更新されます
1件ずつ処理する場合は各行の「発送処理」ボタンから、複数選択して一括処理する場合は「選択した注文を発送処理」ボタンから可能です。
