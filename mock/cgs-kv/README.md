# CGS（カタログギフトスタジオ）KV 案：湾曲カードの横送り

studio.yui.gift の KV 検討用モック。weichie.com の形式に倣い、
「贈る場面」5つのカードが右から左へ回り続け、下の索引と連動する。

- `index.html` … モック本体（1ファイル完結。`imgs.js` だけ外に出してある）
- `imgs.js` … カード5枚の画像（data URI）
- `gen.mjs` `bbox.mjs` `bbox.json` … 1枚目「周年ロゴのコラージュ」を組む道具

ブラウザで `index.html` を開けば動く。ビルドは要らない。

## 決めごと（触る前に読む）

### 色
`catalog-studio` の `web/styles/app.css` の値をそのまま持ってきている。
DESIGN-RULES §5 の3層（素の値 `--p-*` / 器 `--c-*` / 中身 `--sc-* --pv-* --k*`）を守ること。
ダークモードで言い直すのは【器】だけ。中身を暗くすると、お客様が見ている
出来上がりと実物が食い違う。

### 動き
🚨 回転は【板ごとの Web Animations】で回している。requestAnimationFrame で
毎フレーム transform を書く作りに戻さないこと。メインスレッドが一度でも詰まると
そのままコマ落ちになる（実際それが「カクつく」と言われ続けた原因）。
JS が毎フレームやるのは「いま何番目が正面か」を読むことだけ。

⚠️ 毎フレーム触っていいのは transform と opacity だけ。
`z-index` / `aria-current` / 属性の付け外しは【変わった時だけ】。
特に選択中のタグを太字にすると、切り替わるたびに索引バーが再レイアウトされる。

⚠️ 変形する板に `filter` を付けない（drop-shadow も含む）。変形のたびに
描き直しになって、カードが小刻みに震える。影は `box-shadow` を使う。

⚠️ 輪（`transform-style:preserve-3d` の器）ごと回す作りも試したが、Chrome が
左隣の板を描かなくなる。板それぞれに角度を持たせる今の形にしてある。

### 指送り
- 舞台は `touch-action:pan-y`。最初のひと動き（4px）で向きを判定し、横なら
  `touchmove` を `preventDefault` して縦スクロールに取られないようにする。
  これをしないと、斜めに動かした瞬間に `pointercancel` で送りが打ち切られる。
- 1枚ぶんの移動量は【触り始めに一度だけ】測る。`pointermove` のたびに
  `getBoundingClientRect` を呼ぶと毎秒60〜120回レイアウトが走る。

### カードの形（実測で決めた値。目分量で動かさない）
- 縦横比 0.99 / 角丸 11.5% / 上辺の反り 1.63%
- 左右の辺は【垂直】、下辺も【まっすぐ】
  - 台形（上へ狭まる形）にすると、隣り合う2枚の向かい合う辺が互いに内側へ寄り、
    すき間が上で広く下で狭い楔になる（実測 17→11px）。見本は上から下まで一定。
  - 下辺を反らせると、反ったぶんと箱の下端のあいだにページの地が残り、
    白い帯として見える。影は箱の【外】にしか描かれないので埋まらない。
- 影は `.slot` 本体ではなく `.slot::before` に持たせる（形と影のきわを合わせるため）。
  台形を戻すときは `inset:0 <tp/2>%` に縮めること。
- `backface-visibility` は `visible`。`hidden` にすると 90°を超えた板が消えて、
  奥に回ったカードが1枚も見えなくなる。

### 寸法
- カード幅 `min(82vw,380px)`、輪の半径 = カード幅 × 1.64
- 393pt 実測：カード 322px、隣とのすき間 12px（上から下まで一定）
- 半径を変えるときは実測し直す。台形の有無でも必要な半径が変わる。

## 1枚目のコラージュを組み直す

    node bbox.mjs    # 各ロゴの図版部分（外接矩形）を測る → bbox.json
    node gen.mjs     # 参照の配置に流し込んで collage.jpg を書き出す

⚠️ 元のロゴ画像はこのリポジトリに入っていない（会話に添付されたもの）。
生成済みのコラージュは `imgs.js` の `c1` に焼き込んである。
組み直すには元画像を `gen.mjs` の `U` が指す場所に置くこと。

## 本番に載せる前の宿題

- `prefers-reduced-motion` の自動送り停止を戻す（モックは動きを見せるため外してある）
- 右下の「形を調整」パネルを外す（モック専用）
- 3〜5枚目（社内表彰・クライアントギフト・株主優待）は拾い画のまま。作例カードに差し替える
