贈る場面の数だけ、
カタログはつくれる。

周年記念も、誕生日も、表彰も。予算を決めて3,579点から選び、表紙と挨拶文をつけるだけ。印刷もやりとりの往復もなく、その日のうちに贈り先へ届く形になります。

この案の決めごと

震えを止めた

🚨 カードに filter（drop-shadow と brightness）を掛けたまま毎フレーム回していた。filter を持つ要素は変形のたびにまるごと描き直されるので、そのつど写真の画素がにじんで小刻みに震えて見えていた。

⭐ transform と opacity だけなら GPU の合成で済む。影は box-shadow に移し、奥の暗さは opacity だけで出すようにした。transform も CSS 変数経由をやめて JS が直に書く（変数が変わるとスタイル計算がやり直されて合成に載らないため）。

回り方

🚨 コマ送り（3.6秒ごとに1枚ぶん動いて止まる）をやめ、毎フレーム少しずつ回す連続回転にした。カードは常に右から中央、そして左へ流れる。

⚠️ transition は外してある。毎フレーム JS が値を書き換えるので、残すと常に前の値へ引き戻されて重く・遅れて見える。⚠️ 止まるのは指で掴んでいる間だけ（「常に回っている」ので、マウスを乗せただけでは止めない）。

倣った形

中央固定のカルーセル＋連動する索引（weichie.com / Apple の製品切り替え / Stripe の用途切り替えに共通）。

並べているのは機能ではなく贈る場面。「何ができるか」より「うちの場合はどれか」のほうが先に知りたいことなので、索引もそのまま場面名にしてある。

⭐ カードの上に見出しは置かない。元も写真と浮かせた画面だけで、名前を持っているのは下の索引だけ。カードに文字を乗せると索引と二重になり、絵の面積も削れる。

歪みのつくり方

🚨 最初の版は横移動＋静止した反りで、平らな板が滑っているだけだった。正しくは縦軸まわりの回転＋遠近で、中心の1枚だけが正面を向き、両隣は回った分だけ細く見えて奥へ下がる。

倣い先はサイトの外ではなく本番の中にある。TopUses（導入事例の下の「贈る場面」）の orbIn* が perspective(1400px) rotateY(-108deg) translateZ(-260px)。遠近の値もそこに合わせた。

⚠️ 遠近は親に置く。子に perspective() を書くとカードごとに別々の消点ができて、並びが球にならない。

カードの形

🚨 左右は直線だった。外へ膨らませていたが、実測すると直線からのずれは幅 1000px に対して 0〜2.5px＝ほぼ直線で、上端が下端より 2.7% 狭い台形。少し下から見上げた遠近そのもの。

🚨 下辺の向きも逆だった。上辺が上・下辺が下に膨らむ「枕型」にしていたが、キャプチャを測ると上辺も下辺も上へ反る三日月型（実測：上辺 2.4%／下辺はごく浅く同じ向き）。カメラがカード下端よりやや下にある画角なので、両方が同じ向きに反る。消点も perspective-origin:50% 116% でカードの下へ置いた。

角丸は 7% → 4.5%（丸すぎた）。値は右下の「形を調整」で独立して動かせる。

曲がりの大半は回転が作るので、反り自体は浅くしてある（球の面に沿っている分だけ）。

⚠️ clip-path は box-shadow を落とす。影は親の drop-shadow。角丸だけの border-radius では辺は曲がらない。制御点を枠の外に置くと、その分が切り落とされて辺が平らになる。

ダークモードを入れた

ご指示どおり切り替えを付けた。DESIGN-RULES §5 の手順のまま、言い直したのは②役割の層だけ。見る人の設定は3通りあるので（ライト／ダーク／指定なし）、data-theme と prefers-color-scheme の両方を書いてある。

⚠️ 差し色は暗い地で藍紫 #5B4BE8 が沈むので、ネオン --p-indigo-300 に振っている（app.css に実測 5.97 と書いてある色）。

暗くしたのは器だけ

カードの写真は、暗くしても明るいまま据え置き。③部品の層に置いて、面の言い直しから外してある。

写真はお客様に見せる絵であって、このサイトのUIではないため。§5 の「プレビューの中身は入れない（確定）」をそのまま広げた形。暗くして確かめてほしいのはここ。

差し色を橙にしない

元ネタは選択中のアイコンを橙〜赤にしている。ここは藍紫／ネオンを使った。

「サイト内から赤い要素と黒ボタンをなくす」（2026-08-11 saito）が生きているため。#F01E00 はロゴ・印刷物の色として残っているが、画面には出さない。
